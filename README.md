# Differential Testing Whitepaper

Teal Insights whitepaper: "Proving the Numbers Match", on differential testing as the validation standard for reverse-engineered Excel models.

**Status: draft.** This whitepaper and its accompanying technical standard are working drafts, and their content may change.

The whitepaper is published as a GitHub Pages site from `index.html` in this repository: https://teal-insights.github.io/differential-testing/

[technical_standard.md](technical_standard.md) is the differential testing standard a parity harness must meet: the precision policy, parity-report convention, acceptance bar, pre-flight checks, coverage design, and a conformance checklist.
